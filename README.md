### LIVE FEATURES

- **FLOAT SWIPING TRUSTED SHOPS** - Auto-swipes trusted businesses every 4 sec
- **FOR ALL GOOD AND SERVICE SEARCH** - Search across all shops and goods in database
- **GOODS**
    - Retailers - Sold in **numbers** (single items)
    - Wholesalers - Sold in **packets / bundles / boxes** (bulk)
- **SERVICES**
    - Pharmacy / Clinic / Saloon
    - Search inside category only (e.g., search inside Pharmacy only)
    - Each shop name searchable with copiable shop link `/shop/{id}`
- **BODA-BODA & TRANSPORT**
    - Location: Kagadi + Destination: All Uganda
    - Fee per km editable by admin, real-time push in 3 sec
    - Calculation: `delivery_fee = km * fee_per_km`
- **CART SYSTEM**
    - Add to cart with quantity + / - inside cart
    - **FOR QUICK DELIVERY, PAY NOW** - Flutterwave redirect (red button from cart)
    - **PLACE ORDER NOW** - WhatsApp order
    - Copyable Payment API Link for quick delivery
- **ADMIN PANEL - GOD MODE**
    - Single account creation (hashed with salt, never in code)
    - Create button deletes forever after creation
    - Login via hashed password check
    - Edit: Fee per km, Flutterwave link, Payment API link (copyable)
    - Add shops & goods - pushes to all customers in 3 sec real-time
    - No Firebase, no Gmail storage needed
